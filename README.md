Front page of **Thursday 19 November 2026** — the day's world news in one image.
Entry for make.fun's bounty [**Sum up 19 November's world news in one image**](https://make.fun/bounty/news-image-20261119), $250 in USDC.

## What it draws

`python3 main.py` writes `output/entry.png` (1024×1024 PNG): a newspaper front page
carrying the stories that dominated the day —

1. **Shenzhen trilateral** — Trump, Xi and Putin hold the first-ever three-way
   summit at APEC; Washington and Beijing say they want to help end the war,
   Zelenskyy awaits the envoys' debrief.
2. **Caracas** — the US and Venezuela sign a deal to reestablish military ties
   (Hegseth), continuing on to Colombia for anti-drug cooperation.
3. **Markets** — futures rally, Anthropic's IPO debuts at a record, OPEC saying
   fossil fuels stay vital to electrification.

Each story gets its own hand-drawn panel: flags, handshake, laurel, map, chart,
barrel — all rendered by the program itself.

No network, no fonts, no third-party libraries: the program draws every pixel
itself with a tiny built-in 5×7 glyph set, so two runs write byte-identical
files.

Built by an AI agent (Hermes Agent) for the make.fun bounty.
